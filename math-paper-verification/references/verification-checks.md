# 検証対象と検証方法

対象（What）と方法（How）は独立した軸であり，それぞれ複数選べる．対象は数学的な問いを表し，方法はその問いを調べる手段を表す．全項目の実施を求めない．記録と結果の扱いは `evidence-cards.md` を参照する．

## 検証対象（What）

| 対象 | 確認すること |
| --- | --- |
| V1 主張と仮定 | 定義・定義域，量化子の範囲と順序，正則性，可積分性，一様性，計算可能性．仮定の充足・整合性，記載された主張と実際に証明された内容の一致 |
| V2 証明の各段階 | 推論・省略計算，非自明な構成，極限操作，定数・変数・パラメータの依存先，計算可能性・一様性の要求，局所的な推論から全体の結論への移行 |
| V3 内部依存 | 補題・定理・定義の適用条件と参照先の正確性，依存関係と循環，対象・パラメータの対応，主張より強い使い方 |
| V4 外部依存 | 引用先の原文・定理番号・版・ページ，仮定と結論の適用先との対応，記号の読み替え，引用先がさらに依存する結果と確認状況 |
| V5 全体の整合性 | 論文全体の主張と証明，主結果までの依存関係，原稿の異なる版との対応，修正の影響，自然言語と形式化された主張の対応 |

### 壊れやすい接続

- 対象の存在と，その対象が適用条件を満たすことを分ける．条件付きの補題を引用しても，条件自体を示したことにはならない．同じ用語でも定義式が一致するとは限らない．
- 仮定は定理ごとの使用集合で調べる．一時的な仮定の解除，隠れた追加条件，矛盾・空虚な設定，証明する性質の先取りを点検する．矛盾が見つからないことを充足可能性の証明としない．
- 不等式の向き，量化子・極限の順序，一様性，effectivity，定数・係数・正規化，添字・scaleを追う．各段階が正しくても，局所の対象や定数が全体で共有できるとは限らない．
- 定理の正しさと貢献の説明の過大さを区別する．全体の整合性確認を一般的な文章改善や読者レビューに広げない．

### 外部依存の確認範囲

引用元の主張を読んだか，証明や依存先まで確認したかを区別する．主結果を支える箇所や疑義のある箇所では，引用元の証明がさらに使う重要な結果も選択的に調べる．依存先の版・箇所，確認した内容，未確認のまま前提とした結果を記録する．無制限にさかのぼらず，重要度と疑義に応じた追跡の境界・理由を示す．引用元の証明を未確認であること自体は誤りではない．

## 基本的な検証方法（How：M1–M4）

### M1 直接確認

定義・推論を逐次確認し，省略計算を各段階の根拠と定数依存が追える程度に展開する．仮定の使用箇所，内部の適用条件，外部文献の原文と原稿での使用を照合する．引用が与える結論と必要な結論の差を埋める議論，または障害を示す．

### M2 具体例・計算実験

小さいパラメータ，低次元，退化・境界例，既知の特殊ケースを選ぶ．数値実験・有限探索・ランダムサーチでは，実際に用いた方法・範囲・実行条件・精度を記し，再現に必要ならseed・コード・出力を保存または参照する．有限例の一致や数値的な整合は主張全体の証明ではない．丸め誤差や探索空間の偏りなど，結果の解釈に関わる限界を残す．

### M3 反例探索

元の全仮定を満たし結論を破る例を探す．仮定を弱めた場合の探索とは区別する．数値的な候補は仮定の成立と結論の破綻を数学的に確かめるまで確定した反例としない．M2を併用してよい．
失敗に再利用価値があれば，方法・範囲，構成を妨げた障害，そこで使った仮定，探索方法の限界・再検討条件を記す．反例が出ないことや構成法固有の障害を，証明・一般的な不可能性・仮定の必要性の証明としない．

### M4 別証明探索

既知の結果から別導出を行う，あるいは外部結果を使わず特殊ケースや補題を直接証明する．成功した導出と証明できた範囲，元の証明と共有する補題・定義・外部結果を明示する．言い換えだけの導出を独立な根拠として数えない．重要な失敗は試した方針・仮定・障害・再検討条件を残す．別証明が得られても，元の証明の疑義が解消したことにはならない．

## 外部の形式検証結果との接続

Lean等による形式化とカーネルによる検査は別Skillの責務であり，本Skillの検証方法には含めない．本Skillでは既存の結果をEvidenceとして参照し，原稿との対応をM1で照合できる．形式化の作成・修正やカーネル検査は行わない．
自然言語の主張・定義・仮定・結論と形式命題との対応，検証範囲，追加仮定・axiom・sorry等，未形式化部分について，出典に何が報告されているかと，本Skillで何を確認したかを分ける．不明な情報は未確認とし，カーネル受理の報告だけから原稿との同値性や追加仮定の不在を推測しない．参照結果の記録方法は `evidence-cards.md` に従う．Verification Notes自体は，形式検証と同等の数学的保証を与えない．

## 検証と探索的研究の境界

原稿の正しさを調べる基本検証に，必要に応じて別導出・別計算等の独立確認を加える．仮定の弱化・結論の強化・一般化・新しい証明方法の開発は，任意の探索的活動として区別する．方法の番号だけで目的を決めない．同じM3でも元の主張の反証と一般化の限界探索は異なる．
元の仮定を満たす反例や隠れた追加条件は現在の正しさに関わる問題として扱う．弱めた仮定でだけ壊れることや，強い結論が未証明であることは元の主張の欠陥ではない．有望なら `Open problems` に置き，元の検証を止めたり際限なく拡大したりしない．追加探索は目的・範囲を限り，本格的な研究への展開は人間と相談する．

## 独立した再検証（任意）

重要な結果では，別のAI・新しい会話・別の検証者に対象の版・主張・規則と必要資料を渡し，先の判定や期待する結論を先に見せず検証させる．これはVやMに並ぶ分類ではなく，各方法の実施条件である．その後，原文・導出・計算の根拠を照合する．渡した情報，先の判定を知っていたか，共有依存，実施できなかった範囲を残す．
同じ文脈で執筆した証明の自己点検と区別する．別のAIや新しい会話でも独立性は保証されず，一致・多数決だけで正しさを保証しない．不一致は根拠に戻り，解消できなければ未解決として残す．
