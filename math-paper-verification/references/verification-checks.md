# 数学的な確認

対象に関係する観点を選ぶ．すべての項目に機械的な確認やカード作成を要求しない．

| 分類 | 主に確認すること |
| --- | --- |
| C1 外部文献 | 原文の主張・定義・仮定と必要な結論の対応，記号の読み替え，版の差，追加議論の必要性 |
| C2 内部依存 | 補題の適用条件，主張より強い使い方，循環依存，対象・パラメータの対応 |
| C3 計算・推論 | 省略された非自明な操作，不等式の向き，量化子，極限交換，定数・係数・正規化，添字やscale |
| C4 仮定・反例 | 仮定の使用箇所，主張の範囲，退化・境界例，反例や仮定削除で壊れる箇所 |
| C5 独立確認 | 本文とは別の計算・原理・具体例によるsanity check，既知の特殊ケースとの整合 |

## 壊れやすい接続

- 量化子の範囲・順序，一様性，計算可能性（effectivity），定数の依存先を確認する．同じ用語でも定義式が一致するとは限らない．
- 対象の存在と，その対象が適用条件を満たすことを分けて確認する．条件付きの補題を引用しても，条件自体が示されたことにはならない．
- 仮定は定理ごとの使用集合で調べる．一時的な仮定の解除，隠れた追加条件，矛盾や空虚な設定を点検し，矛盾が見つからないことを充足可能性の証明とはしない．
- 証明するはずの性質を仮定していないか確認する．定理は正しく貢献の説明だけが過大な場合は，証明の誤りと区別する．

## 計算・探索・修復

- 省略計算は各段階の根拠と定数依存が追える程度に展開する．再現に必要な方法・範囲・パラメータ・精度・seedを，実際に用いたものだけ記録する．
- 反例は全仮定の成立と結論の破綻を示す．反例が出ない探索や有限例での一致は，主張全体の証明ではない．方法の失敗と主張自体の反証も分ける．
- 修復では，元の主張・仮定を保つ補完と，仮定追加・結論弱化を区別する．後者で解消した場合は「変更後の主張について」と明記し，下流の結果やAbstract等への影響も確認する．
- 修正案やパッチだけでは解決済みとしない．導出・出典などの根拠を残す．著者の同意・保留や，後のレビューで言及されないことは，数学的な解決を意味しない．
