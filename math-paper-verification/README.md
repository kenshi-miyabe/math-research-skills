# math-paper-verification

数学論文の検証とVerification Notesの記録を行うCodex Skill．配置と使用例はリポジトリのREADMEを参照する．

- `SKILL.md`：目的・制約・作業の入口．
- `references/verification-checks.md`：何を数学的に確認するか．
- `references/evidence-cards.md`：カードの欄，候補管理，改訂時の更新．
- `templates/`：新規記録のひな型．`assets/verification.sty`は従来版を維持．

特定プロジェクトの構成例は[保存資料](../docs/examples/master-exposition.md)へ分離し，通常のSkill参照から外している．
