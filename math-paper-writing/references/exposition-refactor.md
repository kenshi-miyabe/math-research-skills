# Exposition Refactor（添付の規則に準拠）

## 目的

数学的内容を保ったまま，論文・章・節の構造を最も理解しやすい形に組み替える．

## ルール

1. 各 chapter / section / subsection に一つの主要な役割を持たせる．
2. main result までの依存関係が短く自然になるように，定義・補題・構成の順序を組み替える．
3. 同時に使う概念と記号を最小限にし，必要になる場所の近くで導入する．
4. 主となる数学的アイディアと技術的な実装・計算を分け，主アイディアが先に見える構造にする．

数学的主張を変える必要がある場合は，構造修正とは分けて指摘する．

## 補足

- theorem / lemma / definition についても，それぞれが担う役割を明確にする．
- 補題は実際の用途に適した形で述べ，不要な一般化を避ける．ただし一般化に独立した数学的価値がある場合は残すことを検討する．
- 新規な部分と標準的な議論を区別する．
